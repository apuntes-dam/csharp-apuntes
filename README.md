# C# · Apuntes

🌐 **Web: https://apuntes-dam.github.io/csharp-apuntes/**

Apuntes y ejercicios de **C#** con la estructura de las unidades de Programación: teoría con ejemplos ejecutados de verdad, ejercicios adaptados y soluciones modelo bloqueadas.

Forma parte de [Practica los Lenguajes de Programación para 1º DAM y 2º DAM](https://apuntes-dam.github.io/apuntes-lenguajes/).

## Cómo está hecho

Web estática con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) publicada con GitHub Pages: el workflow `.github/workflows/pages.yml` construye y despliega al hacer push a `main`. En local:

```bash
pip install mkdocs-material
mkdocs serve
```

Las soluciones modelo están cifradas; solo se ve el comienzo de cada una.
