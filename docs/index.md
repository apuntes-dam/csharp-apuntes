# C#

!!! note "Qué es C#"
    C# es un lenguaje **de tipado estático, orientado a objetos y multiplataforma**, creado por Microsoft y que se ejecuta sobre **.NET**. Se usa para aplicaciones de escritorio y de servidor, servicios web, videojuegos (con Unity) y, con .NET MAUI, aplicaciones móviles. Se parece mucho a Java y a Kotlin.
