# U1: Primer programa en C#

## 1. Contexto

Esta unidad introduce el análisis de problemas, la escritura de programas sencillos y las herramientas para compilarlos, ejecutarlos y comprobarlos.

## 2. Objetivo de aprendizaje

Reconocer la estructura de un programa C# e identificar y relacionar los elementos propios del lenguaje.

| b | Crear proyectos de desarrollo | [1.2](02-lenguaje.md), [1.5](05-entorno.md) |
| c | Utilizar un IDE | [1.5](05-entorno.md) |

## 4. Contenidos

1. [Un programa](01-programa.md): algoritmo, pseudocódigo y su traducción a C#.
2. [Práctica con el lenguaje](02-lenguaje.md): estructura, variables, operadores, entrada y comentarios.
3. [Tipos de datos](03-tipos.md): números, texto, booleanos, colecciones y conversiones.
4. [Pruebas](04-pruebas.md): xUnit.
5. [Entorno](05-entorno.md): instalar, compilar y ejecutar.
6. [Bucles](06-bucles.md): `for`, `foreach`, `while`.

Ver [Prácticas](practicas.md). Se recomienda hacerlas en orden.
