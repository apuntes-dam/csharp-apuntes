# U9.2 · Consultas, borrados y modificaciones

<div class="ej-gate" data-unit="u09" data-nombre="U9 · Bases de datos relacionales"></div>

Sentencias de lectura y escritura sobre la base de datos del apartado anterior, siempre con errores controlados.

## Ejercicio 9.3

**Consultas.** Muestra: (a) todas las líneas del pedido con id 1; (b) la suma de los totales de los pedidos del usuario *Pablo Gil*; (c) los nombres de los usuarios que han comprado un *Teclado*.

## Ejercicio 9.4

**Eliminaciones.** (a) Elimina al usuario *Rocío Vela*; (b) elimina el producto *Ratón* (¿qué pasa si tiene líneas de pedido? resuélvelo); (c) elimina el pedido con id 3, borrando antes sus líneas.

## Ejercicio 9.5

**Modificaciones.** (a) Pon el *Monitor* en oferta, rebajando su precio a 120 €; (b) cambia la línea de pedido con id 3 para que sea del *Teclado* y su precio sea el doble del actual del teclado.
